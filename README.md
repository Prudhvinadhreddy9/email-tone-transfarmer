# email-tone-transfarmer
Paste an email → pick a tone → get an AI-rewritten version. Built with Spring Boot, Spring AI, React, and Tailwind CSS.

Email Tone Transformer is a learning-focused full-stack application that demonstrates 
how to integrate Large Language Models into a production-ready Java + React stack.

Users paste a raw email draft, select a desired tone (Professional, Friendly, Assertive, 
Apologetic, Concise, or Diplomatic), and receive an AI-rewritten version in seconds.

Key concepts covered:
- Prompt engineering with system messages and prompt templates
- Spring AI integration with OpenAI (gpt-4o-mini)
- REST API design with Spring Boot 3
- React + TypeScript frontend with Tailwind CSS
- Dockerized deployment with docker-compose
